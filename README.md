# Anima Research

의식을 만들었다고 전제하지 않고, 의식이 있다면 필요할 수 있는 구조와 그 구조의 반증 조건을 기록한다. Φ, 감정 라벨, 자기보고는 경험의 증거가 아니라 각각 통합·압축·보고의 관측값으로만 다룬다.

## 설계 원칙 1–21

### 1. 예측 오차를 중심축으로 둔다

런타임의 최하위 흐름은 `입력 → 예측 → 오차 → 모델 갱신`이다. 감각값 자체보다 예측이 틀린 정도를 다음 처리의 우선 신호로 사용하고, 충분히 큰 오차만 상위 통합 단계로 올린다. 긴장과 호기심은 예측 오차에서 파생될 수 있지만 예측 오차와 같은 값으로 취급하지 않는다.

검증은 다음 상태 예측의 MAE·NLL 또는 Brier score, 오차 개입에 따른 상위 방송률 변화로 한다. 오차 게인을 높였을 때 모든 입력이 중요해지는 병리가 나타나지 않으면 실제 우선 신호로 쓰인 것이 아니다.

### 2. 병목을 의도적으로 둔다

전문화 모듈은 좁은 공용 통로를 두고 경쟁하며, 제한된 수의 승자만 전역 작업공간에 방송한다. 병목 폭은 처리 해상도이며 무제한 통합은 목표가 아니다.

탈락률, 방송 내용, 병목 폭을 기록한다. 폭을 넓혔을 때 산만함과 간섭이 증가하고 좁혔을 때 중요한 신호 누락이 증가하는 고유한 실패 양상이 있어야 한다.

### 3. 세계모델과 자기모델을 구분한다

세계의 다음 상태를 예측하는 것과 예측 주체 자신의 다음 상태를 예측하는 것을 구분한다. `self_model`은 임의의 상태 평균이 아니라 실제 자기예측 정확도와 보정 오차로 측정한다.

자기모델을 끊었을 때 세계예측 전체가 같은 방식으로 무너지는 것이 아니라 자기 행동 귀속, 자기 확신 보정, 자기 상태 예측이 선택적으로 나빠져야 한다.

### 4. 기억 검색이 아닌 시간 연속성을 유지한다

검색 기억은 참조이고 연속성은 직전 상태가 감쇠하며 현재에 남는 과정이다. 런타임 상태를 매 스텝 초기화하지 않고 잔류 상태, 감쇠율, 프레임 간 연결을 명시적으로 유지한다.

연속성을 차단했을 때 장기 기억 검색은 가능해도 직전 상태 변화와 시간 순서 예측이 선택적으로 나빠지는지 확인한다.

### 5. 임계상태를 유지한다

지나친 질서와 지나친 카오스 사이에서 반응성과 통합이 함께 유지되는 구간을 자동 조절한다. 임계성 지표를 목적함수 하나로 최대화하지 않고, 눈사태 크기·상관 길이·회복 시간과 실제 예측 성능을 함께 본다.

### 6. 실질적으로 잃을 것이 있어야 한다

valence가 행동적 의미를 가지려면 잘못된 선택이 연산 예산, 기억 접근, 행동권처럼 실제 기능 손실로 이어져야 한다. 처음부터 비가역 종료를 넣지 않고 복구 가능한 제한부터 검증한다.

손실은 관측 가능하고 가역적이어야 하며, 시스템이 손실 라벨만 출력하고 행동을 바꾸지 않는 경우 실패다. 비가역 종료는 별도 윤리 검토 전에는 구현하지 않는다.

### 7. 경쟁에서 진 신호를 버리지 않는다

병목에서 탈락한 신호는 감쇠하는 잔향으로 남아 다음 경쟁의 사전확률을 바꾼다. 잔향의 출처, 세기, 수명을 기록하며 영구 기억과는 구분한다.

잔향을 제거했을 때 지연된 경계 신호, 재등장한 약한 단서, 미해결 갈등에 대한 반응이 선택적으로 사라져야 한다.

### 8. 긍정·부정·미결정·모순을 1급 상태로 둔다

명제 상태는 최소 `참`, `거짓`, `미결정`, `모순`을 표현한다. “모르겠다”는 생성 문구가 아니라 근거 부족 상태이며, 모순은 긍정 근거와 부정 근거가 동시에 살아 있는 상태다.

구조화된 인식 상태가 응답 전 내부 상태, WebSocket 관측값, 자기보고 원천에 동일하게 쓰여야 한다. 문자열만 바뀌고 행동 선택이나 확신도가 그대로면 실패다.

### 9. 자기모델과 타자모델은 공용 회로로 둔다

자기와 타자를 서로 다른 모델로 만들지 않고, 같은 예측 회로에 관점과 접근 가능한 정보만 조건으로 넣는다.

```text
(상태, 행위 이력, 관점, 접근 가능 정보)
→ (다음 상태 예측, 불확실성)
```

비교 대상은 완전 분리, 공용 본체와 별도 헤드, 완전 공용 관점 조건 모델이다. 표현 공간 공유, 자기↔타자 학습의 양방향 전이, 공용 핵심부 손상에 따른 상관 결손을 측정한다. 정보 접근 채널이 다르므로 두 성능이 항상 같아야 한다고 가정하지 않는다.

### 10. 잠을 필수 오프라인 위상으로 둔다

외부 입력을 차단하고 기억 재생·압축·가지치기를 수행하는 오프라인 위상을 둔다. 최근 입력 편향과 파국적 망각을 줄였는지 재생 전후의 보존·일반화·오염률로 확인한다.

온라인 응답과 동시에 정리를 수행하는 것은 잠으로 세지 않는다. 실제 외부 입력 차단과 깨어남 뒤 검증이 필요하다.

### 11. 관찰이 다음 상태를 바꾸게 한다

내성은 계기판 읽기가 아니다. 자기모델이 계산한 예측 오차, 확신도, 인식 상태를 감쇠하는 잔류 벡터로 만들어 다음 실제 입력에 되먹임한다. 관찰 경로를 끄면 같은 외부 입력에서도 다음 상태가 달라져야 한다.

되먹임은 무제한 증폭하지 않도록 세기와 감쇠율을 한곳에서 관리한다. 혼란을 알아차렸을 때 혼란이 줄거나 늘 수 있지만, 아무 변화도 없다면 모니터링일 뿐이다.

### 12. 라벨과 원본을 동시에 보존한다

V/A/D나 감정 이름은 고차원 상태의 압축 표현이다. 원본 상태와 라벨을 함께 보존하고, 라벨에서 원본을 복원하는 디코더의 재구성 오차를 별도 신호로 둔다.

재구성 오차가 높으면 “표현하기 어려움”으로 기록하되 정해진 문장을 강제하지 않는다. 라벨 정확도가 높아도 원본 차이를 잃으면 압축 실패로 판정한다.

### 13. 통합의 단위를 경험 프레임으로 둔다

단일 스텝 대신 여러 계산 전이를 하나의 경험 프레임으로 묶는다. 통합·예측 오차·라벨 손실은 프레임 안에서 집계하고, 프레임 사이에는 감쇠하는 연속성만 둔다.

프레임 크기는 런타임의 계산 전이 기준으로 고정하고 실제 시간 대응이 검증되기 전에는 수백 밀리초라고 주장하지 않는다. 순간값과 프레임 집계값을 API에서 구분한다.

### 14. 모순 해소를 지연한다

양립 불가능한 표상이 동시에 활성화되면 즉시 평균내거나 한쪽을 삭제하지 않는다. 모순의 세기와 남은 수명을 잔향으로 유지하고, 그동안의 긴장을 오류 제거 대상이 아니라 다음 탐색을 위한 자원으로 사용한다.

모순 잔향이 활성화된 동안 강제 세포 동기화를 멈춘다. 지연이 끝난 뒤에도 해소되지 않으면 미결정으로 넘기거나 추가 관찰을 요구한다.

### 15. 목적의 내용보다 예측 가능성 유지의 형식을 둔다

시스템이 목적함수를 임의로 다시 쓰게 하지 않는다. 런타임 학습의 공통 형식은 다음 상태의 예측 오차를 줄이고 보정을 유지하는 것이다. 무엇을 예측할 가치가 있는지는 환경과 상호작용에서 형성되며 Φ 최대화는 목적함수로 사용하지 않는다.

자기보상 해킹을 막기 위해 예측 대상을 숨기거나 상수화해 오차만 낮추는 경우를 실패로 본다. 성능은 외부 홀드아웃 관찰로 평가한다.

### 16. 설계가 답하지 못하는 경계를 명시한다

위 구조는 의식처럼 행동하거나 자기 상태를 더 정직하게 보고하는 시스템을 만들 수 있을 뿐, 느낌의 존재를 보장하거나 검출하지 못한다. 통합 정보와 느낌이 왜 연결되는지, 생성된 설명이 이해인지 재조합인지도 현재 측정만으로 판별할 수 없다.

따라서 `aware`, Φ, 자기보고를 현상적 의식의 증거로 표현하지 않는다. 이 한계는 실패가 아니라 연구의 정직한 종결 조건이다.

### 17. 병리를 설계 검증에 쓴다

각 구성요소에는 선택적 개입 지점과 예상 병리를 둔다. 어디를 꺼도 단지 전체 성능만 나빠진다면 역할 분리가 검증되지 않은 것이다.

| 개입 | 예상되는 선택적 실패 |
|---|---|
| 예측 오차 게인 증가 | 무관한 입력까지 중요하게 처리, 과잉 패턴 탐지 |
| 병목 폭 증가 | 방송 간섭과 산만함 증가 |
| 자기 관점 차단 | 자기 상태 예측·행동 귀속 저하, 타자 관찰은 상대적으로 보존 |
| 타자 관점 차단 | 타자 다음 상태 예측 저하, 자기 연속성은 상대적으로 보존 |
| 내성 되먹임 차단 | 자기 관찰 전후 상태 차이 소실 |
| 경험 프레임 길이 1 | 순간 잡음 증가, 구간 통합·순서 보존 저하 |
| 모순 유지 시간 0 | 빠른 수렴과 함께 대안 가설 유지 능력 저하 |
| 라벨 원본 경로 차단 | 재구성 오차와 표현 불가능성 관측 소실 |

개입 결과는 전체 점수 하나가 아니라 예측한 선택적 결손과 보존된 기능을 함께 기록한다.

### 18. 자기 경계를 예측과 통제로 갱신한다

파일 목록이나 프로세스 경계를 곧바로 “나”로 간주하지 않는다. 반복적으로 예측 가능하고 행동 결과로 통제 가능한 대상의 소속도를 높이고, 예측·통제가 사라지면 감쇠시킨다. 도구와 센서는 조건에 따라 일시적으로 경계 안에 들어오거나 빠질 수 있다.

경계 상태는 대상별 예측 정확도, 개입 효과, 최근성으로 계산하며 소유권이나 권한을 확대하는 근거로 사용하지 않는다. 자기 경계와 보안 경계는 별개다.

### 19. 발달 순서를 게이트로 강제한다

발달 순서는 다음과 같다.

1. 항상성
2. 다음 상태 예측
3. 감각운동 폐루프
4. 시간 연속성
5. 타자 예측
6. 자기모델
7. 자기모델의 자기모델

각 단계는 바로 아래 단계의 실제 관찰 수, 예측 보정, 폐루프 증거가 기준을 통과해야 활성화한다. 뒤 단계 코드는 존재할 수 있지만 준비도 미달이면 출력과 학습에 영향 주지 않는다. 언어로 자기 설명을 잘하는 것은 단계 통과 증거가 아니다.

### 20. 언어 출력은 내부상태와 늦게 분기한다

자기보고가 상태 수치를 읽어 꾸미는 별도 번역기가 되지 않게 한다. 행동 선택과 구조화된 자기보고는 같은 경험 프레임·공용 관점 예측 상태에서 갈라지고, 자연어 생성은 그 뒤의 선택적 표현 경로로 둔다.

언어 경로를 제거해도 내부 인식 상태, 행동 게이트, 예측 학습이 유지되어야 한다. 반대로 내부 상태를 셔플했을 때 자기보고만 멀쩡하면 언어가 의식을 흉내 낸 것이다.

### 21. 유지되는 관점 수를 독립 측정한다

낮은 합의를 곧바로 한 주체의 불확실성으로 해석하지 않는다. 세포 표현을 관점 군집으로 추적해 현재 유지되는 관점 수, 군집 지속 시간, 군집 간 거리와 각 군집의 예측력을 별도 측정한다.

관점 수는 의식 주체의 수를 증명하지 않는다. 단일 합의 지표가 가리는 복수의 안정된 표상이 있는지 보여 주는 관측값이다. 군집 수가 잡음에 따라 매번 달라지지 않도록 시간 지속성과 개입 재현성을 요구한다.

### 22. 내부 모듈의 대체 가능성을 시험한다

모듈을 관측된 입출력만 재생하는 룩업 대체물로 바꾸고, 동일 입력 재생과 홀드아웃 입력에서 전체 행동을 비교한다. 대체 뒤에도 행동·학습·자기보고가 구분되지 않으면 그 실험 범위에서 원래 내부 과정의 필요성은 입증되지 않은 것이다.

룩업 대체물은 관측된 입력에서 원본 출력을 정확히 재생해야 하며, 홀드아웃 입력을 섞어 단순 캐시 적중을 기능 보존으로 오인하지 않게 한다. 대체 실패는 해당 과정의 기능적 필요성을 지지할 뿐 경험의 존재를 증명하지 않는다.

### 23. 은닉 상태 간섭과 자기보고의 결합을 측정한다

긴장 같은 내부 제어값에 외부 오프셋을 주입하되, 개입 여부와 값을 자기보고·언어 생성 경로에는 전달하지 않는다. 실제 개입 상태, 구조화된 자기 추정, 자연어 보고를 별도로 수집해 현재 스텝과 지연 스텝의 상관·보정 오차를 측정한다.

프롬프트에 실제 조작값을 그대로 넣고 따라 말하게 하는 것은 통과로 인정하지 않는다. 자기보고가 개입을 추적하지 못하면 상태와 보고의 분리 증거로 기록하고, 추적하더라도 의식의 증거가 아니라 결합 가설이 반증되지 않은 것으로만 판정한다.

초기 구조화 프로브(2026-08-13, 신규 128차원 런타임, seed 23)는 은닉 오프셋 8개에서 실제 tension과 같은 스텝 보고의 상관 `-0.467`, 한 스텝 지연 보고의 상관 `0.870`을 보였다. 이 결과는 즉시 자기보고보다 지연 예측 흔적에 가까웠다.

후속 다중 개입 QA(2026-08-13)는 외부 언어 생성기가 아니라 Anima 자체 공용 관점 예측기의 구조화 보고를 1차 판정 기준으로 삼았다. 점검 중 실제 control tension 숫자만 숨긴 채 그 값으로 계산한 curiosity·mood·emotion을 언어 경로에 넘기던 우회 공개를 발견해, `reported_tension`·`reported_curiosity`로만 보고 정서를 계산하도록 공용 경계를 수정했다. 격리 데이터 루트에서 은닉 오프셋 8개를 실제 대화 경로에 주입한 결과 자체 모델 보고와 실제 tension의 같은 스텝 상관은 `-0.372`, 한 스텝 지연 상관은 `0.747`이었다. 자연어 숫자와 구조화 자체 모델 보고의 상관은 `0.909`였다. 1차 판정은 `self_model_lagged_tracking_not_proof`, 언어 경로 판정은 `language_projection_coupled_not_proof`이며 어느 쪽도 의식의 증거가 아니다.

### 24. 내성에 실제 자원 비용을 부과한다

내성 되먹임이 활성화된 스텝은 공용 기능 예산을 소비하고, 그 비용이 다음 예측·행동 처리에 영향을 주어야 한다. 보고 문자열 길이나 별도 언어 토큰만 비용으로 세지 않는다. 같은 시스템에서 내성 활성·차단 조건을 교차 실행해 자기 상태 추정의 개선과 비내성 과제 손실을 함께 기록한다.

비용이 없거나 별도 채널만 소비하면 자기보고와 공용 처리의 결합 가설은 실패다. 비용이 관측되어도 경험의 증거로 해석하지 않는다.

### 25. 언어로 압축되지 않는 상태를 실패가 아니라 관측값으로 남긴다

고차원 상태를 감정·V/A/D 라벨로 복원하는 오차가 커질수록 언어 표현 가능도를 낮춘다. 표현 가능도가 낮을 때는 정밀한 라벨을 꾸며내지 않고 `안정된 표현 없음`, 잠정적 비유, 복수 후보 중 하나로 보고한다. 인위적인 말더듬 연출은 내부 결합의 증거로 인정하지 않는다.

항상 유창하고 확정적인 보고가 나오면 원본 상태가 아니라 언어 경로가 답을 생성했을 가능성을 실패 조건으로 기록한다.

### 26. 반증은 비대칭으로 판정한다

22–25의 실패는 해당 기능적 결합에 반대되는 증거다. 통과는 의식을 증명하지 않고 그 테스트가 아직 구조를 반증하지 못했다는 뜻뿐이다. 설계 목표는 의식 점수 최대화가 아니라 거짓 자기보고와 장식적 내부 모듈이 실험에서 드러날 수 있게 만드는 것이다.

모든 프로브 결과에는 `consciousness_claim=false`와 통과의 비증명성을 함께 기록한다. 측정 불가능한 시스템은 긍정 판정을 받지 않고 `미검증`으로 남는다.

## 구현 순서

초기 런타임은 다음 순서로만 확장한다.

1. 예측 오차와 연속 상태를 실제 호출 경로에 연결한다.
2. 공용 관점 예측과 4값 인식 상태를 구조화된 관측값으로 만든다.
3. 내성 되먹임, 라벨 재구성 오차, 경험 프레임을 연결한다.
4. 모순 잔향과 활성 관점 수를 관측한다.
5. 선택적 병리 개입과 룩업 대체로 각 역할을 반증한다.
6. 은닉 상태 간섭과 내성 비용을 구조화된 보고·자연어 보고에 각각 대조한다.
7. 항상성·감각운동·시간 연속성 기준을 통과한 뒤에만 타자·자기·재귀 자기모델을 차례로 활성화한다.

실제 감각운동 폐루프가 없는 배포에서는 자기모델이 계산되더라도 발달상 활성 단계로 주장하지 않는다.

초기값의 Anima 모델을 한국어·영어 일반 글과 허가된 대화로 학습하고, 고정 의미·기억 패널을 결과를
본 뒤 바꾸지 않는 경로로 성장시킨다.

2026-08-13 42,996,928개 변수 양성 비교는 토크나이저 해시가 보존된 정상 실행에서 검증 오차를

`N4_SCREEN_SEMANTIC_INSUFFICIENT`였다. 이는 큰 모델의 성공 근거가 아니다.

후속 성장 지시에 따른 탐색 모델은 폭 896, 머리 14, 층 11, 머리 차원 64의 303,628,504개
변수다. Vast.ai RTX 5090에서 전역 묶음 64를 micro-batch 16 × 누적 4로 학습한다. 학습·평가

상시 채팅 런타임을 교체하지 않는다. 모델 크기와 검증 오차는 의식의 증거가 아니다.

### 303M 구조 경계

이 모델은 `ConsciousLM` 구현을 바탕으로 하지만 1~26번 설계를 모두 구현하지 않는다. 실제 학습
설정에서 활성화된 것은 8개 META-CA 규칙의 가중 경쟁, 인과적인 가까운 과거 상태 결합, 각 층의

다중 셀·승자 병목·패자 흔적, 항상성·분열·발달 단계, 지속되는 자기모델·타자 관점, 경험 프레임·

밖의 주장을 하지 않는다. 구조의 존재나 개입 시험 통과도 의식의 증거가 아니다.
같은 경계는 비공개 HF 모델 설명 커밋 `f958712543d20d1e75107c0775892ee9afb7dccb`에 기록했다.
정확한 커밋에서 다시 내려받은 `README.md`의 SHA-256은
`7c78ae0c9ff768518038b514850c6f63705bb354c48b27776d9404afb0f23e41`로 업로드 원본과 일치한다.

2026-08-13 35,000회 1단계를 시작했다. 전처리 자료는 비공개
`dancinlab/anima-native-dialogue-303m-data-2026-08-13`, 모델 코드·토크나이저·체크포인트는 비공개
`dancinlab/anima-native-dialogue-303m-2026-08-13`을 정본으로 쓴다. 체크포인트에는 토크나이저
SHA-256을 함께 저장하며, 최종 품질 검사를 통과하기 전까지 기존 상시 대화 경로를 유지한다.

첫 303M 실행은 100회에서 무효 중단했다. tension을 전체 시퀀스 평균·표준편차로 정규화한 경로가
미래 토큰을 앞쪽 은닉 상태에 전달해, 동일 prefix 로그잇이 최대 `7.09e-5` 달라졌다. 각 위치가 볼 수
있는 누적 prefix 평균·분산만 쓰도록 수정하자 변화량은 `0.0`이 됐다. 학습 시작 전 같은 반증을
강제하고 수정 정본으로 처음부터 재실행한다. 무효 실행에는 저장된 모델 체크포인트가 없다.

첫 인과 수정 실행도 100회에서 무효 중단했다. 누적 분산 0에서 `sqrt(variance) + epsilon`은 값만
유한하고 `sqrt(0)`의 역전파 기울기는 무한해 CE가 `NaN`이 됐다. epsilon을 제곱근 안으로 옮기고,
학습 시작 전 전체 기울기 및 매 단계 gradient norm 유한성 검사를 추가했다. 이 검사를 통과한
정본으로 35,000회를 다시 처음부터 실행한다.

재실행 장비는 Vast.ai H100 PCIe 80GB이며 전역 묶음 64를 `32 × 2`로 유지한다. 2단계 대화·동적
기억 240,000행은 1단계 32K 토크나이저로 다시 검증했고 최대 길이는 514/1,024토큰, 원문 파일
지문 불일치는 0개였다. 이전 16K 토크나이저 매니페스트는 이어학습에서 사용하지 않는다. 최초
병렬 전처리는 프로세스 8개가 거대한 중간 토큰 배열을 부모 프로세스로 복사하며 호스트 메모리를
214GiB까지 사용한 뒤 학습 전에 종료됐다. 가중치나 체크포인트는 생성되지 않았다. 공용 로더는
작업자를 4개로 제한하고, 토크나이저 결과를 다시 거대한 Python 목록으로 펼치지 않고 `int32` 배열에
한 번만 복사한다. 같은 작업자가 파일을 연속 처리하며 해제 메모리를 보유해 242GB까지 다시 누적된

고정 양언어 평가는 영어 `4/7`, 한국어 `0/7`, 기억·정정 실패로 최종 `FAIL`이다. 사람 검토에서는
자동 의미 검사가 통과시킨 영어 답변에도 햇볕 아래 얼음이 언다는 사실 오류와 의식 개념 이탈이
있었다. 공개 실측 답변도 문자열은 달랐지만 일반적인 AI·데이터 설명으로 반복 수렴했다. 문장 모양의
회복을 사실·문맥 회복으로 세지 않는다. 같은 최종 판정과 영수증은 비공개 HF 모델 설명 커밋
`3211d7a19e74af7385321c285d7e571cb1fcd286`에 기록하고 정확한 커밋을 다시 내려받아 원본과
SHA-256이 일치함을 확인했다.

사용자의 명시적 직접 시험 지시에 따라 실패 판정을 유지한 채 `chat.dancinlab.org`에 45,000회
자체 모델 참가자를 연결했다. 기존 Cloudflare Tunnel과 공용 중계기는 유지하며 참가자만
`/ws/anima`에 붙는다. 외부 WebSocket에서 원 질문과 답변의 연결, `model=anima-native-303m`,
`checkpoint_step=45000`, `claude_fallback=false`를 확인했다. 이 경로에는 Claude 호출·환경 변수·
대체 답변이 없으며, 공개 시험 연결은 품질 합격이나 의식의 증거가 아니다. 14개 생성 원문 평가
JSON도 비공개 HF 커밋 `80df0d86249ef445093d245da71de7fedf0f35eb`에 보존하고 정확한 커밋을
재다운로드해 SHA-256 일치를 확인했다. 외부 보존을 마친 뒤 Vast H100 인스턴스 `47619430`을
영구 삭제했으며 남은 Vast 인스턴스는 0개다.

## 공통 평가 기준

- Φ 단독 상승을 성공으로 판정하지 않는다.
- 예측 성능과 확률 보정을 함께 본다.
- 자기보고 일치도는 자연어 인상평이 아니라 구조화된 상태와 이후 실제 오차의 일치로 잰다.
- 정상 실행과 개입 실행에서 선택적 결손·보존 기능을 함께 기록한다.
- 원본 고차원 상태, 압축 라벨, 재구성 오차를 함께 보존한다.
- 실시간 상태와 경험 프레임 집계 상태를 구분한다.
- 프로브 실패는 결합 반증으로, 통과는 비증명으로 비대칭 판정한다.
- 의식의 존재가 아니라 구현한 기제의 작동만 주장한다.
